# Detective Case: The Missing Trophy

## Project Name
Detective Case: The Missing Trophy

## Description
This is a beginner-friendly Flask web game where the player acts as a detective investigating a missing school trophy. The player visits the suspects, interviews them, studies the clues, and finally makes an accusation.

## Technologies
- Python
- Flask
- HTML
- CSS
- Jinja2

## Installation
Create a virtual environment in PowerShell:

```powershell
python -m venv venv
```

Activate the virtual environment:

```powershell
venv\Scripts\activate
```

Install the project dependencies:

```powershell
pip install -r requirements.txt
```

## Running the Project
Start the Flask app:

```powershell
python app.py
```

Then open the following URL in a browser:

```text
http://127.0.0.1:5000
```

## Game Flow
```text
Home
 ↓
Suspects
 ↓
Interview
 ↓
Clues
 ↓
Accusation
 ↓
Result
```
